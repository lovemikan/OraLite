# Oracle 轻量客户端

面向 **Oracle 初学者** 和 **熟悉 Excel 但不熟悉 Oracle** 的用户的图形化数据库工具。
不用写 SQL 也能查数据、改数据，写操作前自动备份、可一键还原，结果一键导出 Excel。

> 运行环境：Windows 10/11 + Python 3.9 及以上（需带 tkinter，Python 官方安装包默认自带）

---

## 一、安装与启动

**方式 A：绿色便携版（推荐，目标机器无需 Python）**

双击 **`打包便携版.bat`**，几分钟后得到：

| 产物 | 说明 |
| --- | --- |
| `dist\Oracle轻量客户端.exe` | **单个文件，约 25 MB**。自带 Python 运行环境和全部依赖，拷到 U 盘/任意电脑双击即用，不用安装 Python，也不用装 Oracle 客户端 |
| `dist\Oracle轻量客户端(调试版).exe` | 同上，但出错时会弹出控制台显示错误信息，排查问题用 |
| `dist\Oracle轻量客户端-便携目录版\` | 可选。运行 `打包便携版(目录版).bat` 生成，启动更快、几乎不会被杀软误报，但要整个文件夹一起拷 |

便携行为说明：

- exe 所在目录会自动生成 `UserData\`（连接档案、备份、SQL 历史、设置都在这里），**随身带着走**
- 不想带数据时，设置环境变量 `ORACLE_CLIENT_HOME` 指向别的目录即可（此时写该目录）
- 首次启动会往临时目录解压运行环境，约慢 1~3 秒；之后同一次开机内再启动会快很多
- 拿到 exe 后想快速确认环境是否完整：`Oracle轻量客户端(调试版).exe --selftest`

**方式 B：源码运行（开发/二次修改）**

1. 安装 [Python 3.9+](https://www.python.org/downloads/)（安装时勾选 **Add Python to PATH**）
2. 双击 **`安装依赖.bat`** —— 自动创建虚拟环境 `.venv` 并安装依赖
3. 双击 **`启动客户端.bat`** —— 启动程序

依赖包：`python-oracledb`、`openpyxl`、`ttkbootstrap`、`pillow`
（python-oracledb 为「瘦模式」，**无需安装 Oracle 客户端/Instant Client** 即可直连数据库）

> 若启动时一闪而过或报错，请改用 **`启动客户端(调试模式).bat`**，会保留控制台显示错误信息。

## 二、核心功能

### 1. 连接与多任务
- 连接配置保存在本机，口令使用 **Windows 账户级加密（DPAPI）** 存储
- 支持服务名 / SID / 完整连接串 / SYSDBA / Instant Client 厚模式
- **内置演示数据库**：没连 Oracle 也能完整体验所有功能（第一次启动自动连接）
- 可同时连接多个库，任意开多个子窗口并行工作；「窗口」菜单支持层叠、平铺、快速切换

### 2. 查询（不用写 SQL）
- **查询向导**（Ctrl+G）：选表 → 选字段 → 加条件 → 排序 → 看语句 → 执行，5 步完成
- 条件支持：等于/不等于/大于小于/包含/开头是/结尾是/属于列表/为空/介于…之间，可任意组合 AND / OR
- 字段类型感知：数字填了文字会拦下来，日期支持 `2024-01-15`、`2024/01/15 08:30`、`20240115` 等写法
- **生成的语句先展示给你看，可以直接改，改完再执行**
- 左侧对象浏览器双击表名即可打开数据窗口

### 3. 结果处理（像 Excel 一样）
- 点列标题排序（升序/降序）；结果内关键字筛选
- 右键复制整行，**可直接粘贴到 Excel**；双击查看宽表单行详情
- 导出 **Excel(.xlsx)** / CSV / JSON / INSERT 回放脚本，支持导出“当前筛选视图”
- 支持分页「加载更多」，避免大表一次拉爆内存
- 数据表窗口**分页浏览**：取回多少行就能看到多少行（“最多行数”即取数上限），
  每页 100~5000 行可选，首页/上一页/下一页/末页自由翻页

### 4. 增 / 删 / 改 + 备份还原
- 新增行、修改行、删除行都有向导，自动按主键定位，禁止无条件的整表更新/删除
- 执行写操作前弹出确认框：**默认勾选「备份受影响数据」**，并可预览将影响多少行
- 备份保存为本地文件，可查看备份了哪些行
- **一键还原**：UPDATE 用备份值覆盖回去（有 ROWID 时精确定位），DELETE 把行插回去，INSERT 把行删掉
- 默认不自动提交，工具栏随时 **提交 / 回滚**

### 5. 运维 SQL 模板库（只读诊断）
- 内置 30+ 条排障常用查询，按动线分六类：快速体检 / 会话与锁 / SQL 性能 /
  空间与存储 / 对象与结构 / 容量与增长
- 模板支持参数（如"阻塞超过 N 秒""TOP N 条"），填完即时渲染出**真正会执行的 SQL**，
  所见即所跑；可一键复制到 sqlplus、也可以丢进查询窗口继续改
- **权限预检**：进界面就知道当前账号跑不跑得了；缺权限会写明缺什么（例如
  `SELECT_CATALOG_ROLE`），部分模板会自动降级到 `V$` 之外的等价视图
- 每条模板带**结果解读**：哪些列超过什么值要警惕、下一步该查什么
- 收录的全部是只读查询，不提供任何改数据的模板
- 三处入口：运维概览 →「SQL 模板」页签、查询窗口工具栏「模板」、工具菜单 `Ctrl+Shift+T`

### 6. 其它
- SQL 编辑器：关键字高亮、行号、多语句一次执行、执行计划（EXPLAIN PLAN）、历史与收藏
- 表结构查看：字段、类型、主键、默认值、注释、索引、建表语句
- 浅色/深色多套主题，字体大小可调
- 常用快捷键：F5 执行、F9 执行选中、Ctrl+N 新查询窗口、Ctrl+T 数据窗口、
  Ctrl+G 查询向导、Ctrl+B 备份还原、Ctrl+R 刷新对象、Ctrl+C 复制选中行、
  Ctrl+Shift+T 模板库、Ctrl+Shift+O 运维概览、Ctrl+Shift+D 数据库档案

## 三、典型使用流程

```
连接管理 → 填主机/端口/服务名/用户/口令 → 测试连接 → 保存并连接
   ↓
工具 → 查询向导（或左侧双击表名）
   ↓
选字段、加筛选条件、选排序 → 生成语句 → 确认/修改 → 执行
   ↓
结果表格：点列头排序 / 右键复制 / 导出 Excel
   ↓
要改数据：选中行 → 修改行… / 删除行… → 勾选备份 → 执行
   ↓
改错了：工具 → 备份与还原 → 选中记录 → 还原到数据库
```

## 四、目录结构

```
Oracle客户端/
├─ 启动客户端.bat           启动（无控制台）
├─ 启动客户端(调试模式).bat   启动（保留控制台，便于排查）
├─ 安装依赖.bat             创建虚拟环境并安装依赖
├─ 打包便携版.bat           打包成单个 exe（绿色便携，可在无 Python 的机器上运行）
├─ 打包便携版(目录版).bat    打包成文件夹版（启动快、不易被杀软误报）
├─ 绿色便携版说明.txt        随 exe 一起放在 dist，可直接给用户看
├─ requirements.txt
├─ assets/app.ico           程序图标（打包时自动生成）
├─ dist/                    打包产物（exe）
├─ tools/
│   ├─ build_exe.py         打包脚本（PyInstaller）
│   ├─ entry.py             打包用的入口
│   └─ dev_check.py         开发自检（核心逻辑 + 界面冒烟）
└─ oracle_client/
   ├─ main.py               程序入口（支持 --version / --selftest）
   ├─ core/                 核心层（与界面无关，可单独测试）
   │   ├─ db.py             Oracle / 演示库适配器、会话与元数据缓存
   │   ├─ sqlbuilder.py     引导式 SQL 生成、语句解析与拆分
   │   ├─ validator.py      按数据类型校验与格式化
   │   ├─ backup.py         写操作备份与还原
   │   ├─ exporter.py       Excel / CSV / JSON / SQL 导出
   │   ├─ config.py         设置、连接档案、SQL 历史
   │   └─ secure.py         Windows DPAPI 口令加密
   └─ ui/                   界面层
       ├─ app.py            主窗口、菜单、会话与子窗口管理
       ├─ windows.py        SQL 查询窗口 / 数据表窗口（多子窗口）
       ├─ builders.py       查询向导、增删改向导、写操作备份确认
       ├─ grid.py           数据网格（排序/筛选/右键菜单）
       ├─ editor.py         SQL 编辑器（高亮、行号）
       ├─ schema.py         对象浏览器
       └─ dialogs.py        连接管理、导出、设置、备份中心、表结构等
```

数据保存位置：

- **便携 exe**：exe 同目录的 `UserData\`（整个可以跟 exe 一起拷走）
- **源码运行**：`%APPDATA%\OracleClient`
- 两者都可用环境变量 `ORACLE_CLIENT_HOME` 强制指定；备份默认单独放在 …\备份（可设置里改）

命令行参数（源码运行 / 调试版 exe 均可）：

```bat
python -m oracle_client --selftest     # 运行环境自检：依赖、资源、导出、演示库是否完好
python -m oracle_client --version
```

## 五、常见问题

| 问题 | 解决办法 |
| --- | --- |
| 双击 bat 一闪而过 | 用「启动客户端(调试模式).bat」查看报错 |
| 提示缺少 tkinter | 重新运行 Python 安装程序 → Modify → 勾选 tcl/tk and IDLE |
| **DPY-3016 缺少 cryptography** | thin 模式必需。源码运行装 `pip install cryptography`；便携 exe 请用**重新打包**的版本（旧版漏打此库），或改勾 thick 模式 |
| DPY-3015 口令验证器不支持 | 老库（10g/11g）常见。请 DBA 重置一次口令，或勾选 thick 模式 |
| DPY-6000/6005 连不上监听 | 主机/端口不通，检查防火墙与监听状态 |
| ORA-12170 连接超时 | 检查主机/端口、防火墙、数据库监听 |
| ORA-12514 | 服务名或 SID 填错，可在连接设置里切换「服务名 / SID」 |
| ORA-00911 无效字符 | SQL 末尾多了分号（程序会自动处理，手写 PL/SQL 时留意） |
| 提示无法备份 | 备份需要先 SELECT 受影响的行；同义词/视图可能读不到，必要时在确认框里手改抓取语句 |
| 还原后没生效 | 记得在工具栏点「提交」（或开启自动提交） |
| 结果太多很慢 | 在查询向导/数据窗口里调小「最多行数」 |
| exe 被杀软拦截/删除 | PyInstaller 单文件 exe 常被误报，加白名单即可；目录版几乎不会被误报 |
| exe 启动慢 | 单文件版每次运行要解压到临时目录（首次 1~3 秒），属正常现象 |
| exe 起动后报错没提示 | 用「调试版」exe，或命令行跑 `Oracle轻量客户端(调试版).exe --selftest` |
| 想换个位置存数据 | 设置环境变量 `ORACLE_CLIENT_HOME` 指向目标目录 |

## 六、开发自检

```
.venv\Scripts\python.exe tools\dev_check.py            # 核心逻辑 + 界面冒烟
.venv\Scripts\python.exe tools\dev_check.py --no-gui   # 只跑核心逻辑
.venv\Scripts\python.exe -m oracle_client --selftest   # 运行环境自检
```

打包：

```
.venv\Scripts\python.exe tools\build_exe.py --mode onefile   # 单文件 exe（默认）
.venv\Scripts\python.exe tools\build_exe.py --mode dir       # 目录版，启动快、不易被杀软误报
.venv\Scripts\python.exe tools\build_exe.py --mode both --clean-all
```
